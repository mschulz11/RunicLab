# Pläne

Arbeitspläne für Umbauten, die mehrere Schritte brauchen und einen Zwischenstand
zum Nachlesen verdienen. Ein Plan ist **kein** Statusbericht: Er beschreibt die
Schritte und wird nach Abschluss gelöscht oder als ADR (`docs/adr/`) verdichtet.
Offene Aufgaben gehören in GitHub-Issues.
